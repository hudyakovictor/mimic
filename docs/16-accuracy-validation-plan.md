# План достижения и доказательства качества детектора

## Что означает «95%»

Число нельзя обещать до слепого теста. Для продукта целевой критерий задаётся как **sensitivity ≥ 95% при заранее выбранном FAR**, например FAR ≤ 1%, с нижней границей 95% bootstrap confidence interval. Accuracy без указания доли масок и обычных видео вводит в заблуждение.

## Единица сравнения

1. ASR выделяет слова и устойчивые 2–3-словные фразы с временными метками.
2. Для каждого фрагмента сохраняются версия ASR, язык, confidence, устройство, условия, 478 landmarks, head pose и 30×33 нормализованная motion-кривая.
3. Baseline строится отдельно для человека + языка + слова/фразы только из проверенных genuine-сессий.
4. Сравнение использует DTW, стандартизованное отклонение региональных признаков, задержки фаз и качество трекинга.
5. Решение выдаётся только при наличии минимум трёх зрелых сопоставимых фраз. Отсутствие данных — `INSUFFICIENT_DATA`, а не подозрение.

## Что нужно добавить для production-качества

- **Мультимодальность:** landmarks + optical flow кожи + rPPG/цветовые микровариации + граница маски/блики + audio-video lip sync. Одна мимика не покрывает качественные маски.
- **Персональные baseline:** не смешивать разных людей; минимум 10 подтверждённых сессий и несколько устройств/ракурсов на зрелое слово.
- **Hard negatives:** грим, борода, очки, стоматология, усталость, болезни лицевого нерва, низкий FPS, сильная компрессия.
- **Защита от утечки:** person-, session- и device-disjoint splits; все фразы из одного видео принадлежат одному split.
- **Калибровка:** isotonic/Platt только на validation; порог фиксируется до blind test.
- **Human-in-the-loop:** система ранжирует риск и evidence, а не устанавливает личность или факт мошенничества автоматически.

## Минимальный протокол данных

- Не менее 100 участников и 3 независимых сессий на участника для пилота.
- Отдельная выборка реальных силиконовых масок разных производителей и толщины; replay/deepfake считаются отдельными threat classes.
- Баланс языков и фонетических классов. Приоритетные фразы должны содержать губные `/p b m/`, губно-зубные `/f v/`, широкие гласные и быстрые переходы.
- Двойная разметка двумя специалистами; спорные записи исключаются из обучения и идут в adjudication.
- Отчёт: ROC/DET, FAR/FRR, sensitivity, specificity, EER, Brier, ECE и 95% CI по людям, устройствам и условиям.

## Безопасность и ограничения

Это биометрическая обработка: нужны явное согласие, шифрование, tenant isolation, сроки удаления, аудит доступа и процедура удаления данных. Результат не должен быть единственным основанием для отказа человеку или обвинения. Медицинские особенности и качество видео могут менять мимику и создавать ложные срабатывания.
