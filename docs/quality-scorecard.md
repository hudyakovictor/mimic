# 50-factor architecture scorecard

Score each 0–2: absent, partial, complete. Release target: at least 90/100 with no zero in security, data integrity or model governance.

1. Clear problem statement
2. Explicit non-goals
3. Measurable success metrics
4. 80/20 scope discipline
5. Human review workflow
6. Modular boundaries
7. Dependency inversion
8. Framework-independent domain
9. Idempotent jobs
10. Explicit state machines
11. Immutable decisions
12. Versioned schemas
13. Versioned models
14. Reproducible decisions
15. Quality gate
16. Insufficient-data outcome
17. Stable timestamps
18. Gap policy
19. Pose normalization policy
20. Feature provenance
21. Curated enrollment
22. Poisoning prevention
23. Disjoint evaluation splits
24. Calibration
25. Explainable evidence
26. Model rollback
27. Drift monitoring
28. Tenant isolation
29. RBAC
30. Biometric encryption
31. Secret management
32. Upload hardening
33. Audit trail
34. Retention/deletion
35. Least-privilege raw video access
36. API contract
37. Event compatibility
38. Pagination/idempotency conventions
39. Typed frontend client
40. Accessible status design
41. Loading/error/empty states
42. Unit tests
43. Contract tests
44. Integration tests
45. Golden-video tests
46. Security tests
47. SLOs
48. Metrics/logs/traces
49. Runbooks and rollback
50. Documented delivery roadmap

The scaffold covers all factors at architecture/contract level. Runtime implementation is intentionally incomplete where validation or infrastructure is required.
